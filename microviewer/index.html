3D MicroViewer

Open a z-stack

Load a multi-page TIFF: an ImageJ hyperstack, an OME-TIFF, or plain pages stacked in depth. Drop it anywhere on this page, or use Load stack.

The file is read in this browser and never leaves it. The 3D view needs WebGL2.

Each slice of the stack is placed at its depth. Drag to turn the stack; the view opens looking straight down, as the microscope does, which is the same picture as flattening every slice into one. Tilt it to see which crossings are real junctions and which are structures passing over each other at different depths.
